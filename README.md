## 研究解释边界

本项目测量特定文本分布的下一词预测损失与输出漂移。数学文本损失下降不等于数学推理能力提高；C4也不是Pythia的原始预训练语料。固定样本库大小、累计回放token和实际计算成本分别计量。pilot、正式对照、补充探索将独立标记。
