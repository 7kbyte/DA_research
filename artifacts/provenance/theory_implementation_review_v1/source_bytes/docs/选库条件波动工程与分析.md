# 选库条件波动工程与分析

本文件落实《补充实验预案》B，不改变主实验。生成器为 `scripts/make_bank_variance.py`，独立分析为 `scripts/analyze_bank_variance.py`，实现模块为 `src/replay_study/bank_variance.py`。均不执行模型推断；生成器仅加载 CPU token/教师统计产物并做选库，不启动训练，也不读取测试或行为分数。

## 前置条件与固定量

生成器必须显式给出 parent formal registry，并核对 `docs/protocol_status.json` 当前 active 指针。父注册表的所有条目都须 active/formal、完成冻结目标预算、实际回放计数正确且有 strict deterministic / warn_only=false 证据；任何旧 provisional、pilot 或未完成父批次均拒绝。然后唯一选取父 B4、training seed11、b=.05 的完整 10M 配置。共享 LR/λ、优化器、目标数据、精度、后端、完整学习率日程均从这个已完成父配置复制，不能沿用已作废校准值。

固定 generation seed11 的正式池与原始 teacher NLL/features，核对 pool、statistics、teacher revision 和源 SHA。此处不重新生成文本或重新计算教师特征。默认交叉矩阵为 B4 random / M 五层 NLL 比例分层 / C 聚类，K=20、196 块，selection seeds=1001–1010，共 60 份库和训练配置。每块 512 token 时分别为 10,220 与 100,156 唯一预测 token；实际数从 mask 计算，不靠文件大小或卡上 token 数猜测。

训练配置里的 seed 始终为 **11**。补充 registry 明确分别记录 training_seed、generation_seed、selection_seed，且刻意不提供会被误当主训练 seed 的通用 seed 字段。phase 固定为 `conditional_bank_variance`，主分析器会拒绝读取它。固定 training seed 保持目标流及回放行索引 shuffle 的随机规则；由于库内容和库内行顺序随选样产物变化，回放文本的实际顺序不相同，结果条件于整个选库算法产物，不宣称只隔离无序集合的作用。

## 产物与冻结

每个 bank 保存 `.pt` 与 `.json`，含源 pool SHA、teacher statistics SHA、选择 indices、独特容量、抽样算法、NLL 五层组成、均值/样本 SD/分位数和选库 wall time。聚类计时是选库计时的子项，不能再次相加。生成与联合教师统计为主实验已有共享成本；本补充新增的是 60 次选库及之后实际启动的训练。

preparation_manifest 保存父注册表完整快照、父配置/摘要 SHA、每份库/manifest/config SHA、CPU 线程数及准备时间。科学注册表哈希忽略 active/status 这两个管理字段，允许主代理在审计后标记授权状态，其他内容改变会被分析器拒绝。

`queue_template.json` 是带 prepared_only=true、launch_authorized=false 的对象，不是调度器可以直接读取的 job 列表。它已经列出完整命令与 summary-copy 输出位置，但必须在主实验审计和主代理明确授权后，另行冻结真正的训练队列。生成器不提供自动启动入口。

## 独立统计

先分析全部 bank 的教师 NLL 组成和选库代价，再在实际训练完成后读取固定曝光的验证端点。初始验证模型必须来自同一 revision 和执行政策，包含完整 execution_provenance。不存在模型摘要或未达到预算时不填造端点，必须显式 `--allow-partial` 才能输出准备诊断。

每个方法/K 的均值与 SD 以 **selection draw** 为重复单位，n_draws=10、n_training_seeds=1、n_generation_pools=1。成对比较先按同一 selection_seed 求 M−B4、C−B4，再计算 draw 差值的均值与样本 SD（ddof=1）。相同 draw 标签不意味着不同选择算法消耗完全相同的随机数，不宣称强共同随机数设计。该变异条件于固定池、固定训练流及当前严格数值执行；不能冒充十个独立训练 seed、十份独立语料或总体模型不确定性。

教师 NLL 组成均衡不证明梯度代表性，也不保证 retention 收益。库内 NLL 的 SD 与跨 draw 的 bank 均值 SD 是不同量，表中各自标名。PNG/PDF/SVG 的点表示选库 draw，误差棒是 draw 间 SD；尚无训练结果时图明确写 prepared banks only / partial。测试入口未在当前脚本启用，未来如需测试必须另行冻结，不能根据验证或测试的有利 draw 筛选子集。

## 固定池的有限总体解释

把已冻结候选池看成大小为 \(N\) 的有限总体。对固定参数和任意固定标量 \(z_i\)（例如块均值NLL或一个梯度投影），记总体均值为 \(\bar z\)、样本方差定义的总体量为 \(S^2=\sum_i(z_i-\bar z)^2/(N-1)\)。若随机组无放回均匀抽取 \(k\) 块，则

\[
\mathbb E\bar z_B=\bar z,\qquad
\operatorname{Var}(\bar z_B)=\frac{1-k/N}{k}S^2.
\]

对于按固定教师NLL划出的层，记层容量 \(N_h\)、配额 \(k_h\)、权重 \(W_h=N_h/N\)。若使用加权估计 \(\sum_hW_h\bar z_{B,h}\)，各层独立无放回时方差为

\[
\sum_hW_h^2\frac{1-k_h/N_h}{k_h}S_h^2.
\]

本实现实际对选出的等预测长度块直接求均值，层权重是 \(\widetilde W_h=k_h/k\)，而非额外做重要性加权。因此整数配额导致的条件均值偏差精确为 \(\sum_h(\widetilde W_h-W_h)\bar z_h\)，方差中的 \(W_h^2\) 也须替换为 \(\widetilde W_h^2\)。理想比例分配的简式只能作解释，不能抹去当前有限容量与舍入；协议如实记录这些配额，不因结果改变训练权重。

教师NLL层通常直接约束NLL标量的层内变化，却不保证任意梯度投影的层内变化小；有限总体、配额取整和训练非线性还会进一步影响比较。因此不能从NLL均值的较低抽样方差推导终点验证NLL或保留指标的较低方差。聚类代表的抽样机制也不符合上述分层无放回公式，只能按预定draw重复作条件描述。本补充的十个draw既不是独立语料总体，也不是十个训练seed；这些解析式不会增加实际实验重复数。

## 使用示例

```bash
# 仅在父 active formal 全部完成后可通过；不会启动训练。
python scripts/make_bank_variance.py \
  --parent-registry /path/to/completed_active_formal_registry.json \
  --output artifacts/bank_variance_410m_v1 --cpu-threads 2

# 准备完成但还没训练时，只做明确标记的条件库组成诊断。
python scripts/analyze_bank_variance.py \
  --registry artifacts/bank_variance_410m_v1/registry.json \
  --baseline /path/to/matched_initial_validation.json \
  --output results/analysis/bank_variance_410m --allow-partial
```

实际生成尚受父实验完成条件约束；不能把单元测试里的小型合成 fixture 当成正式 60 库资产或论文模型结果。
