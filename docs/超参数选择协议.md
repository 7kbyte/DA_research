# 超参数选择协议

λ 校准网格冻结于 **2026-11-06T03:45:41.238121+00:00**，早于任何 λ 校准训练启动。机器可读协议见 `docs/hyperparameter_selection_protocol.json`；验证数据与银行 tensor 的 SHA256 均在该文件记录。

学习率阶段使用 seed 101、B0、每个候选恰好 2,000,000 个 target prediction tokens，候选为 1e-5、3e-5、1e-4。按 target 验证 NLL 最低选共享学习率；已完成并选择 **1e-5**。该阶段的执行和结果在 `results/pilot_lr_selection.json` 记录；本文件对已完成的学习率阶段作记录，不声称该文件在该阶段之前创建。

λ 候选固定为 **0.05、0.5、1、5**。每个候选均运行 B1（C4 CE）、B2（C4 forward KL）、B3（生成文本 CE）、B4（生成文本 forward KL），共 16 个独立 pilot。全部使用 seed 101、共享 LR=1e-5、2,000,000 个 target prediction tokens、b=0.05，因此累计 replay 恰好 100,000 个 prediction tokens。microbatch=16，梯度累积=4，输入长度=512。K、累计 replay exposure 和 λ 分别记录；两个 bank 均为 196 chunks / 100,156 prediction tokens。

每个 pilot 完成固定预算后，评估 v2 的 target、C4、WikiText 验证集。所有验证使用 FP32 权重与 BF16 autocast，并计算 frozen initial teacher 到 student 的完整词表 KL，单列 teacher 前向和 KL 计算成本。初始指标复用 `results/pilots/lr_validation_initial.json`。pilot 不读 test；不使用 pilot 中间最佳点替代最终固定预算指标。

每组评分为：

`S = (Ltarget - Ltarget_initial) + 0.5 * ((Lc4 - Lc4_initial) + (Lwiki - Lwiki_initial))`

每个 λ 的总评分是四组 S 的无权算术均值，选择最低者。只有计算出的浮点均值严格相等时才视为平手，平手取更小 λ。完整 16 个结果全部有效且预算一致后才选择；缺失、失败或预算不符时不输出选择。共享 λ 同时应用所有 replay 方法，M/C/D 无独立调参。

正式计划为八组×三 seed（11、22、33）共 24 组，B4/M 各增加 b=0.01、0.10×三 seed，共 36 组；每组 10M target prediction tokens、每 50 step 验证、只保留最终完整训练 checkpoint 和 target 验证最优 model-only checkpoint。当前仅实现正式配置生成能力；实际生成与启动需 root 后续授权。
