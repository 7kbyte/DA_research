# 中文报告渲染

主报告的 Markdown 是可编辑源文件，PDF 通过 WeasyPrint 66.0 渲染，嵌入 Noto Serif CJK SC 字体。图表来自实际结果 CSV/JSON 与标准绘图脚本；正文中的解析示意图会单独标明，不当作模型实测结果。

Python 依赖版本见 `requirements-report.lock`。系统需提供 Pango、Fontconfig 等 WeasyPrint 依赖。本次平台没有 ensurepip，因此采用独立 target 目录，不更改正在训练的 PyTorch 环境：

```bash
python -m pip install --target .report-deps -r requirements-report.lock
PYTHONPATH=.report-deps python scripts/render_report.py \
  --source 研究报告.md \
  --font-file artifacts/reporting/NotoSerifCJKsc-Regular.otf
```

渲染器输出 PDF、HTML 及 `.render.json`，记录 Markdown、字体和 PDF 的 SHA256。字体来源哈希与许可位于 `artifacts/reporting/`；字体在便携归档中提供，Git 默认忽略其二进制文件。PDF 已嵌入所用字体，阅读成品不需要本地安装该字体。

本次 PDF 视觉复核使用隔离安装的 pypdfium2 4.30.0，将页面栅格化后检查中文、表格、图例及分页。仅主报告和文献综述直接采用此 Markdown 渲染方式；含原始 LaTeX 推导的辅助文档应保留其数学源格式，不能将尚未排版的公式冒充完成的出版 PDF。
