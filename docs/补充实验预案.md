# 补充实验预案（正式主结果与测试损失查看之前制定）

制定时间：2026-11-06 04:02 UTC。硬截止不变：2026-11-07 03:26:32 UTC。

主线仍为Pythia410M、2M唯一目标token、10M目标暴露、8组×3seed及B4/M预算敏感性，共36配置。以下用于充分利用剩余计算资源，分别标为补充实验，不与主36组混成一份无条件结论。是否启动由真实吞吐和剩余截止预算决定；未做项目如实列出，不填造结果。

## A. 损失权重敏感性与适应—保留曲线

共享λ便于控制因素，但CE和KL的梯度尺度及有限库噪声不同，共享选参不能代表每个方法各自的最优性能。因此计划在主数据/评估v3、b=.05、K=100156、10M目标暴露下，对B1/B2/B3/B4/M/C检查λ∈{.01,.05,.1,.5,1,5,10}，seed仍11/22/33。与主实验完全相同的配置直接复用，不重复计数。D与B4若主实验确认一致，不为每个权重重复计算空对照。

用验证数据确定任何用于单点比较的λ，测试只评估冻结选择或呈现完整预先规定曲线。每个方法同时报告适应与两个旧分布结果；不只展示对其有利的λ。若资源不足，优先完成B4/M的全部权重，再补B1/B2/B3/C。

## B. 有限回放库的选样波动

主seed把训练顺序、生成池与bank抽样同时改变，不能单独识别分层是否降低选样波动。补充固定Pythia410M、生成pool seed11及训练shuffle seed11，只改变选样随机种子1001–1010，比较random、五层NLL分层和聚类。库规模拟20或196块（10220/100156预测token），b=.05、共享λ及目标10M不变。

此处重复单位是同一候选池上的bank抽样，并非十次独立预训练或独立数据总体。报告bank均值/分布波动、验证与测试成对差异，明确条件于固定训练流和生成池。选择随机性结果不能冒充主实验训练seed的不确定性。

## C. 更大目标库与较长适应

已准备约20M唯一FineMath预测token及匹配去污染评估`artifacts/data_extended`。它是原四个shard的更长确定性前缀，包含原训练库，不是独立总体重复。较大的训练库会与原v3评估产生新近重复，因此本组必须使用扩展数据自己的验证/测试集。

优先考虑410M与1B在20M唯一目标库上训练100M目标预测token，比较8组、三seed；再根据吞吐考虑2.8B的50M目标暴露和B0/B1/B2/B4/M五组。每个模型从各自最终预训练checkpoint开始，用各自冻结教师生成回放，不能把410M生成库称为1B/2.8B的自生成库。模型tokenizer已验证一致。

每个模型使用同样的独立pilot流程选择共享LR/λ，pilot与正式seed分离；记录短pilot不保证长训练全局最优的限制。长训练使用独立完整学习率计划，不把改变总预算后的续训冒充主10M实验的自然延续。

不同Pythia大小同时改变每参数预训练token量等因素，仅称模型规模敏感性，不拟合缩放定律、不声称因果隔离“剩余容量”。

## D. 行为能力补充评价

准备采用官方lm-evaluation-harness定义的PiQA与HellaSwag零样本选择题评价，使用公开validation数据并固定样本、格式和评分。除acc/acc_norm外，报告初始正确→错误和错误→正确，以区分遗忘与新增答对抵消。该评价不用于主超参数和bank选择，也不代表所有知识或数学推理能力。

## 资源与停止原则

先确保主36组完整、审计通过，再启动补充训练。可并行提前准备模型、生成池、数据和评价代码。每个任务设置截止，预计无法在剩余预算内完成的任务不启动。至少预留最后两小时完成独立测试、图表、中文研究报告和关键权重持久化。测试结果不得反过来改主协议；探索性改动需新名称、新记录。
