# 方法推导与解释边界

本文依据当前训练、生成、选择代码、训练数据 v2 与独立评估修订 evaluation_v3，区分数学推导、实验假设和可以支持的结论。公式是本项目的推导，不把文献中的有效设置当作普遍保证。

## 预算与损失权重

记目标累计预测 token 数为 \(T_{new}\)，唯一回放库容量为 \(K\)，累计回放预测 token 数为 \(T_R\)。K 是去重后的库容量，另报实际访问的唯一量；重复处理同一 token 会增加 \(T_R\)，不会增加唯一覆盖。定义

\[
b=T_R/T_{new},\qquad p=T_R/(T_{new}+T_R)=b/(1+b).
\]

因此 b=.05 对应总训练 token 中回放占比约 4.76%，不是 5%。真实文本与生成文本还应分开记录候选池规模、库容量、生成成本和教师推断成本。等 token 预算不代表等计算量。有效预测数按因果移位后的 mask 计算，无 padding 的 512-token 块计 511；为提供上下文而重复读取的输入不能再次算作预测暴露。

当前每个优化步分别对目标与回放有效 token 求平均：

\[
L_s=\frac1{n_s}\sum_i\ell_{new,i}
+\lambda\frac1{r_s}\sum_j\ell_{R,j}.
\]

在 \(r_s>0\) 的步，单个回放 token 与目标 token 的损失系数比为 \(\lambda n_s/r_s\approx\lambda/b\)。固定 λ 改变 b，主要改变每步回放估计的样本数、重复率及噪声，同时改变单 token 系数；不能描述为“回放平均损失权重按 b 等比例增强”。若把所有 token 合并平均，则相对系数不同。这里的系数也不等于实际参数更新之比：梯度方向、裁剪、Adam 状态及权重衰减都会介入。预算敏感性必须同时给出 b、λ、λ/b 和实际计数。[Béthune 等](https://proceedings.mlr.press/v267/bethune25a.html)的小比例注入结果不能直接套成此归一化方式下的最优参数。

## 生成 CE 与 forward KL 的关系

冻结教师条件分布为 \(q_0(v\mid c)\)，学生为 \(p_\theta(v\mid c)\)。对固定前缀 c，若下一 token 确由同一教师完整分布采样，则

\[
\mathbb E_{Y\sim q_0}[-\log p_\theta(Y\mid c)]
=D_{KL}(q_0\Vert p_\theta)+H(q_0).
\]

熵项与学生参数无关，所以固定参数处的期望梯度相同。对双方相同的前缀分布再取期望仍成立；前缀本身不必来自教师。项目采用 BOS-only、温度 1、top-p=1、top-k=0、固定长度且 EOS 不停止采样，使未筛选生成池接近这个操作条件；数值精度仍可能带来微小差异。[Marek 等](https://arxiv.org/html/2605.26097v1)比较了生成回放与 KL 约束，不能据此宣称任意有限库上的 CE 与 KL 等价。

温度变换、概率截断、重复惩罚、整序列去重或按 NLL 筛选，均可能改变所保留样本的条件标签分布。此时期望 CE 对应的是变换后的分布，不能仍写成针对原教师的 KL 加原教师熵。即使完全无截断，固定有限库也只是期望的一个实现：在教师与学生条件分布完全相同时，full-vocabulary KL 梯度为零，硬标签 CE 的有限样本梯度通常不为零。反复回放同一库不会自动消除这次抽样误差。KL 消除了给定前缀下下一 token 的标签采样噪声，仍保留前缀覆盖、库选择与优化的随机性；这不是保留效果必然更好的证明。

## 比例分层能够保证什么

M 先按教师平均 NLL 排序，分为五个等频层，再按层大小比例无放回抽样，整数配额采用最大余数法。它约束有限库的 NLL 层比例，未系统偏向低 NLL 文本。若层权重为 \(W_h\)、任一固定梯度投影的层内方差为 \(S_h^2\)，理想比例分配下，固定参数处加权均值的方差近似为

\[
\operatorname{Var}(\hat g_{strat})
\approx k^{-1}\sum_h W_hS_h^2,
\]

其中 k 是抽取的块数，忽略有限总体修正与整数配额。NLL 不是梯度；只有分层与相关梯度分量有关，才可能有明显方差收益。当前有限 k 的舍入也会使抽样比例稍有偏差。优化后的 retention 还取决于更新方向和上下文覆盖，不能由层比例推出。聚类代表同样改变采样分布，特征距离不是遗忘损失。[SSR](https://aclanthology.org/2024.acl-long.77/)的完整方法含指令合成与输出精炼；本项目仅借鉴聚类控制。若精确去重没有删掉候选，D 与 B4 应使用同一 bank，机制空效应应如实报告。

## 评估、不确定性与数据条件

分别定义旧分布损失增量 \(F=L_{old}(\theta)-L_{old}(\theta_0)\) 和目标适应增益 \(G=L_{new}(\theta_0)-L_{new}(\theta)\)。等目标暴露的端点回答固定训练预算问题；在相近目标验证 NLL 处比较只能补充说明适应—保留折中。只选验证检查点，冻结后查看测试。回放也可能改善目标域，因此不预设两者必然交换，[Kotha 与 Liang](https://arxiv.org/html/2603.04964v1)提供了相关实例。

同一 seed 的方法使用一致目标流，报告成对差值与全部训练种子。文档 bootstrap 应共同重采样对应文档及其所有块，再用 NLL 总和除 token 总数；逐块重采样会忽略同篇相关性。它估计固定模型在所选文档总体上的抽样波动，不能替代重新训练的 seed 不确定性，也不包括重新选库、调参或换数据划分的变异。三个 seed 的标准差只作描述，不能借大量 bootstrap 次数制造训练重复。

v2 的精确文档/块跨集合重复为零，并用固定 13gram 阈值清理 FineMath 评估近重复；这不保证语义独立。四个 FineMath shard 的顺序前部、C4 单 shard 前部均是受限样本；不足一整块的文档被排除，结论条件于偏长文本。分布审查发现 v2 FineMath 验证仅 60 篇，其中一篇占 67/264 块（25.4%），前五篇占 56.8%。据此在正式评估冻结前发布独立 v3：FineMath/C4 各分区扩为 1024 块，每篇最多 4 块，长文档由文档 SHA 固定均匀抽样，最大单篇权重降至 0.390625%；训练与 banks 未改，未使用测试损失。该修订改变了评估覆盖和长度权重，并非全新独立语料重复。仍应补报逐文档、等文档权重及 bootstrap 结果；WikiText 保留官方全文分块，仍存在长文章权重较大的条件。版本、新旧重合及清理审计须随结果公开。

[Pythia](https://proceedings.mlr.press/v202/biderman23a.html)使用 Pile 预训练，C4 是替代通用回放与评估分布；数据间仍可能有历史重叠，不能称为原预训练数据回放。WikiText 提供另一文本分布检验，两个集合都不能覆盖全部旧能力。数学 NLL 下降只说明所评数学文本的下一词拟合改善；没有独立任务与答案判定，就不能声称数学推理提升。held-out 教师 KL 是输出漂移诊断，不是知识保留或推理正确率。
