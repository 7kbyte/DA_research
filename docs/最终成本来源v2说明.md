# 最终成本来源 v2

入口为 `scripts/inventory_study_costs_final_v2.py`，来源为 `configs/cost_inventory_final_sources_v2.json`。它复用并校验原 v1 collector 和来源文件，不修改二者，也不改变旧账本口径。当前结果是观测快照，始终保留 `whole_study_completely_instrumented=false`。

```bash
python scripts/inventory_study_costs_final_v2.py \
  --sources configs/cost_inventory_final_sources_v2.json \
  --output results/cost_inventory_final_v2_NEW_SNAPSHOT
```

输出目录必须不存在。每次重收集另建目录；不可覆盖历史 trial。真实首次试收集在 `results/cost_inventory_final_v2_cpu_trial_20261106/`，包括 inventory、CSV、精确来源副本、C record 覆盖表及不可变收据。

| 来源 | 计入方式 |
|---|---|
| A selected export completion | 实际本次调用总 wall/CPU，含逐 record 与 assembly；子计时不再加 |
| A 首次 record 测量 | 作为 export 内子项展示，不新增一次导出 |
| A prepare-only | 独立的前置调用，另计；不与实际 export 调用混同 |
| A durable publication | 与 scratch export 分开的实际发布 wall |
| B60 NLL | 仅由原 manifest/attestation inventory 自动收集；不新增手工 inference 成本行 |
| B CPU analysis | 完整进程 wall/CPU 未测，保持 unknown；已测 guard 仅作为部分下界 |
| B budget watcher | 计尝试 wall/CPU，排除 poll sleep；成功 collection 是其子项，不能再加 |
| A post-test factorial | 仅取小 metadata 中独立 arithmetic/plot 的 1.616210 秒计时，不读取统计表或评分语义 |
| C 每 run draft record | 每个冻结 registry ID 对应一个实际 record，首次创建操作独立计；encode/decode/验收子项不加 |
| C 每模型 completion | 仅 assembly；与先前 draft 分开。缺失或不完整不能算完成 |
| C daemon progress | 含预读、锁等待、poll、draft 和 assembly 的累计上下文，不与子项相加 |
| reservation/grower | 实际单次 allocation 与含等待的 grower 分列；四 grower 和串行父日历不重复相加 |

B 整体分析未被 root 的 Popen 计时，不能用 guard 时间、完成时间戳或进程存活区间补出完整耗时。已明确计时的失败 allocation 保留实际已测成本；其他失败、回滚、未计时协调继续 unknown。A/C grower 的 `initial_bytes` 是容量，不是 initial allocation 的耗时。

C 只检查来源明确列出的三个模型目录，并按冻结 registry 逐 ID 定位 `records/<id>.json`。拒绝目录中未注册的 JSON、跨模型/phase record、非 rc0 来源、缺失验收及重复模型来源。复用 draft 只引用原 record，不按 poll 或 manifest 引用次数重计；canonical identity 绑定 registry ID 和 record 字节 SHA。D 的独立训练仍计入物理训练，零编码的 D draft 只影响该导出操作，不把训练成本抹去。

三个 C publication 的路径与执行尚未授权，因此来源为 `unassigned`，没有计为完成。以后得到实际发布收据，应另建来源版本，显式登记路径/来源 SHA；不能从 reservation 容量或 assembly 完成推断已发布。新增最终评价 scheduler state 也须在新来源版本中显式登记，保持同 ID 定义及完成记录一致。

`exact_cost_sources/` 保存本次实际读到的小 JSON 原字节，以 SHA 命名并 fsync；`collection_receipt.json` 绑定原路径、快照路径和 SHA。这个来源包仅涵盖明确的成本 receipts/authorities 与 C registry records，不重新复制旧训练 events 或评分 payload。缺失来源保留缺失状态，不能伪造 hash。模型、checkpoint、ZIP、TAR 的 GB payload 不会被本 collector 重新读取或散列。

历史完整预哈希读数仍按独立 receipt SHA 去重；此次 cache hit 不代表此次重新读过模型。各阶段 wall 的和不是实验日历长度，也不是 GPU 秒或纯 CPU 工作。原 legacy postprocessing 子账本与新增操作账本保留各自口径，不把两个重叠 subtotal 再相加。

首次 trial 观测到 B60 已完成，因此评价新增 forward 累计为 253；C 仅有 2 个已验收 draft，三个 assembly/publication 均未算完成。这些数字只描述该快照。13 个临时小文件测试覆盖未知总耗时、嵌套去重、等待、不完整 cohort、来源绑定、精确 byte 副本和禁止读取模型 payload。
