**两项代码/归一化补充。** Marek官方代码已钉住检索时commit `5cde463965ff9a9a4f07620703ea884fdea9f622`（晚于论文v1；不能冒称历史运行逐字节复现）。`train_single.py:281–323`在合成缓冲耗尽后用新随机key重新生成；这是暂存新样本的缓冲，**不是始终重复同一固定bank**。其`loss.py`将末位置置零后对全部B×T位置求均值，目标与回放分别归一，再乘λ；本项目按有效预测位置归一。共同长度下两项仍具有一致归一尺度，但不能只凭λ数值跨论文比较约束效果。[固定commit训练代码](https://github.com/martin-marek/forgetting/blob/5cde463965ff9a9a4f07620703ea884fdea9f622/train_single.py#L281)、[loss代码](https://github.com/martin-marek/forgetting/blob/5cde463965ff9a9a4f07620703ea884fdea9f622/loss.py#L13)。

Béthune的公式为`(1−p)L_target+p L_pretrain`。代数上除以`1−p`才得到相对系数`p/(1−p)`，且整体损失尺度改变；若等长token口径相同，暴露比也满足`b=p/(1−p)`。本项目`b=.05`对应混合比例约4.76%，λ则独立控制。SSR的10%按实例计数，其精确有效预测token、跨阶段累计曝光和与本项目一致的CE归一化本次未核实，不能补成0或直接换算。[Béthune §2.3](https://arxiv.org/html/2502.06042v2#S2.SS3)、[SSR §5及官方代码](https://github.com/XMUDeepLIT/SSR/tree/38d2a067ff250f5c1b8967edb14c872c8b5182fc)。
