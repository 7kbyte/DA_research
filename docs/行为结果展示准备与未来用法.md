# 行为结果展示准备与未来用法

本工具只把已解封、已通过独立数值 reviewer 的小表画成报告图。当前验收仅使用手工合成 CSV；没有读取真实行为 score/逐题预测，没有调用原 check/analyze，没有新增推理、区间、检验、选参或排序。原 reviewer、统计、guard、scorer、训练和真实 plan 均不改。

入口为 [present_behavioral_review.py](../scripts/present_behavioral_review.py)。生产调用必须显式给独立 reviewer 的 `COMPLETE.json` 路径和 SHA；工具核 reviewer 源 SHA、原完整分析 COMPLETE、ROOT exact-true authority、plan/manifest 与 first-read 的绑定，再核所有输出 CSV SHA。这里只依赖已成功的 guard/reviewer 证明，不重复读取 checkpoint 或逐题文件。输入在完成出图前再次核五项 stat。

## 固定展示范围

| phase | 完整 logical 端点 | 展示与配对 |
|---|---:|---|
| primary | 72：36 final + 36 best | 12 条件各 seed11/22/33；冻结五对方向，M−B4 另保留三种 b |
| supplement_A | 18 selected final | 六方法各三 seed；自己的冻结验证 λ，另保留全部六个 selected-policy 配对 |
| C410 / C1B | 每模型24 final | 八方法各三 seed；冻结五对方向 |
| C2.8B | 15 final | B0/B1/B2/B4/M 各三 seed；只有存在的 M−B4、B2−B1 |

每个 phase 分开运行。C 的行为范围只有 final，不将 NLL 的 final+best 范围移入行为。缺端点、重复 identity、少 task/score/seed、混模型/phase 或缺固定配对均拒绝。B 选库 draw 实验没有行为评价。

PiQA 与 HellaSwag 分面，`acc_norm` 主展示、`acc` 辅助分别出图。每种 score 包含一张 7×6.45 inch 四面板图：两任务的 accuracy 和相对 matched initial 的变化；final/best 分色、三 seed 分形状，所有点及已有 mean±sample SD 全部保留。上排虚线为各任务 matched initial，下排为零；下排两任务共享 y 范围，上排 accuracy 不强作跨任务绝对量比较。五对配对图 7×3.8 inch，方向均为左减右、越高越有利于左侧。

A 另外两张 score 分开的六对政策图，只使用 `selected_policy_score_resolved_statistics.csv`，保留独立的 `score` 和 `quantity` 列。原 `selected_policy_statistics.csv` 标签碰撞表不读取、不改写。若各方法 λ 不同，该图表示“各自验证选 λ 后的策略比较”，不能称固定同 λ 的 objective 因果效应。A 表中实际存在的同 λ 配对仍单独保留。

数值只做绘图单位转换（accuracy ×100 为百分比、差值 ×100 为百分点）；均值、sample SD、区间不重新计算。所有 reviewer 数字 CSV 原字节复制到新输出目录，包含 seed 个体、CC/CW/WC/WW、条件遗忘/获得、Wilson/问题 bootstrap、actual step/exposure 与身份。图没有按效果删条件。训练成本应按原 actual_run_id 的 full-training 成本去重，不能把 best 曝光当全部训练成本，也不能把 alias、final/best 或问题数量算成额外训练 seed。

sample SD 描述三个固定训练 seed。问题区间条件于固定 checkpoint 与问题独立/可交换的重采样假设；HellaSwag 同源 context/activity 等相关性限制总体解释，不替代训练重复区间。这里没有新增区间或推断。

## 未来真实运行

ROOT 明确给出已解封、已完成独立复核的具体 COMPLETE 后，逐 phase 使用新目录：

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 \
python scripts/present_behavioral_review.py \
  --review-complete /ABS/ROOT_APPROVED_REVIEW/COMPLETE.json \
  --review-complete-sha256 ROOT_APPROVED_COMPLETE_SHA256 \
  --output /ABS/NEW_PRESENTATION_DIRECTORY
```

默认字体为项目已有 NotoSerifCJK；可显式 `--font`，字体字节也绑定 SHA。每图输出 PNG/PDF/SVG，REPORT.md 链接全部图，原数字表同目录保留，COMPLETE 绑定所有输入/输出。目录与 adjacent `*_whole_child_timing.json` 必须不存在；父 timer 包括本次 gate、读取小表、绘图和哈希，子过程不得重复计费。此命令不会触发原分析、评分类任务或 GPU。
