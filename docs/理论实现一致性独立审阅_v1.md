# 理论与冻结实现的一致性：独立审阅

审阅对象是当前方法说明、主报告第3/4节及解释段、冻结生成/损失/训练/选库代码和已核验近邻文献。**未发现需要修改冻结科学代码或重做实验的理论—实现冲突；有三处值得补强的表述，列于末尾。** 本文不增加算法、实验或选参，不读取未解封的1B/2.8B验证、测试或行为分数。原报告、推导及源码已先行保存[字节与SHA清单](../artifacts/provenance/theory_implementation_review_v1/source_manifest.json)；十个科学源码仍匹配正式冻结快照。

1. **联合KL的链式分解正确，但对象是固定BOS下的固定长度续写。** 令 \(x_0=\mathrm{BOS}\)、\(T=511\)，两模型在同一完整词表上定义 \(q(x_{1:T}\mid x_0)\) 与 \(p_\theta(x_{1:T}\mid x_0)\)。在KL有限时，联合对数比的期望等于 \(\sum_{t=1}^{T}\mathbb E_{q(x_{<t}\mid x_0)}\mathrm{KL}(q(\cdot\mid x_{<t},x_0)\Vert p_\theta(\cdot\mid x_{<t},x_0))\)。不包含BOS自身的预测损失，也不是遇EOS终止的变长文本分布；这里没有学生自由生成的前缀。代码确实固定单BOS、温度1、top-p=1/top-k=0、无重复惩罚，并同时关闭显式与模型默认EOS停止；KL方向为完整 \(q\Vert p\)，教师detach。生成有限bank上的均值，只在固定参数、对应抽样测度等条件下具有蒙特卡洛解释；筛选后的M/C不自动继承教师联合KL无偏性。[生成配置与EOS覆盖](../src/replay_study/generate.py#L113)、[完整词表KL及梯度](../src/replay_study/objectives.py#L62)、[现有链式推导](方法推导与解释边界.md#固定长度生成的序列分布解释)

   **数值条件应更明确。** 生成采用BF16 autocast、KV cache；安装的Transformers 4.46.3在采样前将logits转FP32，再softmax与multinomial。训练教师则无cache重算，KL的log-softmax/求和为FP32，反传logits梯度转回其dtype。因此“完整/精确KL”指不截断词表的计算目标，不是实数精确概率。相同权重与温度不足以证明生成操作分布 \(q_{gen}\) 与重算的 \(q_{KL}\) 逐位相同；本次没有测定差异上界。严格确定性解决重复执行一致性，不消除混合精度误差。[生成use_cache及autocast](../src/replay_study/generate.py#L150)、[训练无cache前向](../src/replay_study/train.py#L308)、[上游采样实现v4.46.3，第3219/3247/3249行](https://github.com/huggingface/transformers/blob/v4.46.3/src/transformers/generation/utils.py#L3219)

2. **CE=KL+熵是总体目标恒等式，不能用它把自适应拟合的固定bank梯度当成无偏KL梯度。** 固定 \(c,\theta\) 时，\(\mathbb E_{Y\sim q}[-\log p_\theta(Y\mid c)]=\mathrm{KL}(q\Vert p_\theta)+H(q)\) 成立。训练后 \(\theta=\theta(B)\) 依赖同一bank的标签；条件于 \(B\) 后，旧标签不是新的独立 \(q\) 抽样。因而固定参数的无偏性不能直接推出 \(\mathbb E_B[\widehat g_{CE}(B,\theta(B))-\widehat g_{KL}(B,\theta(B))]=0\)。总体恒等式对代入后的参数仍成立，前提是期望对**独立新标签**取，而非重复的旧标签。初始KL零梯度、有限CE通常非零，是有用的局部区别；不能由逐位置条件平均推出整条相关序列或最终训练梯度方差必降。现文已经写出固定参数、有限抽样和自适应拟合边界，建议仅把这一依赖关系再说直白些。[报告第54行](../研究报告.md#L54)、[推导第35—62行](方法推导与解释边界.md#生成-ce-与-forward-kl-的关系)

3. **Fisher二阶式是局部、固定前缀测度下的解释，不是测得的保留机制。** 在理想平滑模型、\(q_0=p_{\theta_0}>0\)、前缀测度 \(\mu\) 与参数无关、导数可交换等条件下，\(R_\mu(\theta_0+\delta)=\tfrac12\delta^\top F_\mu\delta+o(\|\delta\|^2)\)，\(F_\mu=\mathbb E_\mu J^\top[\mathrm{diag}(q_0)-q_0q_0^\top]J\)。现推导对二阶余项和额外三阶条件的区分正确。有限bank定义的经验**前缀**测度仍保留完整教师标签期望，不等于采样硬标签梯度外积的“经验Fisher”。它也不是原始Pile、C4真实标签或学生自由生成测度的Fisher；重复bank、截尾和每步权重会改变实际累计前缀权重。本研究未估计Fisher谱，不能把局部式、KL小或可逆二次模型的极小点当作AdamW轨迹及旧能力保证。[本项目完整假设与推导](局部Fisher解释与选库诊断.md#固定前缀分布下的局部二次形式)、[Martens 2020，§5—6，印刷页9—11；§11，页23](https://jmlr.org/papers/volume21/17-678/17-678.pdf)

4. **NLL分层的标量组成控制与训练保留必须分开。** 代码稳定排序、五等频层、最大余数配额、层内无放回抽样，随后训练对所选等长块直接求token均值，并未按原层权重补偿。固定有限总体和固定标量 \(z\) 下，实际简单均值的偏差为 \(\sum_h(k_h/k-N_h/N)\bar z_h\)，方差为 \(\sum_h(k_h/k)^2(1-k_h/N_h)S_h^2/k_h\)。现文的理想比例简式及有限总体补充相互一致。已报告的seed11配额40/39/39/39/39和NLL偏移−0.005407是该池的组成描述，不能推广成梯度投影、优化终点或其他池的同样偏差。NLL不是梯度大小/方向，较低组成波动不保证较低训练波动或更好保留。[实际最大余数分配](../src/replay_study/selection.py#L39)、[抽样与配额记录](../src/replay_study/selection.py#L106)、[精确偏差/方差口径](选库条件波动工程与分析.md#固定池的有限总体解释)

5. **λ/b是单token的损失系数近似比，不是两种梯度或Adam更新之比。** 每步实际目标为 \(\sum\ell_{new}/n_s+\lambda\sum\ell_R/r_s\)，各microbatch均除以该步总wanted，累积后只更新一次；没有额外除以累积次数。回放应付量按累计目标暴露取floor并减已消费量，所以准确系数是 \(\lambda n_s/r_s\)，末步/整数余量处不宜写成严格 \(\lambda/b\)。partial chunk保留原始完整因果前缀，只有未消费位置进入CE/KL与计数；上下文重读和padding增加计算但不增加预测暴露。最终先裁剪合成梯度再AdamW，日志范数是裁剪前总L2范数。A中100%阈值超越只能否定“仅大λ开始裁剪”，不能识别目标/回放梯度夹角、有效步长、无裁剪反事实，也不证明λ因裁剪失效。[精确应付量](../src/replay_study/train.py#L113)、[partial上下文与loss mask](../src/replay_study/train.py#L244)、[归一化—反传—裁剪—更新顺序](../src/replay_study/train.py#L598)、[既有事后诊断边界](A梯度裁剪_事后描述性诊断.md#字段含义和完整性)、[Adam原始算法1及§2.1](https://arxiv.org/pdf/1412.6980v9)

6. **C优化的是特定表示空间的代表性，不具有Fisher保证。** 特征先对最后层有效预测上下文位置0…L−2作均值，再L2归一化；MiniBatchKMeans在归一化输入的欧氏空间聚类，选各非空簇最近实例，空簇用最近未选实例补齐。它不是完整梯度、logits参数Jacobian、Fisher或语义覆盖的估计，均值与归一化还舍弃部分序列及尺度信息。当前报告准确称其受SSR启发的控制，未声称完整SSR或新算法。[均值特征提取](../src/replay_study/evaluate.py#L246)、[L2/MiniBatchKMeans/代表与空簇规则](../src/replay_study/selection.py#L127)、[SSR原文§4/5与消融，pp.1418—1423](https://aclanthology.org/2024.acl-long.77.pdf)
