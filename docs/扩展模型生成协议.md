# 可选模型候选池生成冻结协议

授权及冻结记录：`configs/extended_generation_protocol.json`。此批仅准备 Pythia-1B 与 Pythia-2.8B 的补充模型资产，不启动训练或真实任务评价，不改写主 410M 数据、候选池、银行或采样/选择数学。

固定初始教师均为 final step143000，revision 与权重 SHA256 来自 `artifacts/assets/extended_model_provenance.json`。GPU1 串行运行，先 1B，再 2.8B。每个模型按 seed101（pilot）、11、22、33 的顺序，各生成 1,957 个 512-token chunks；每个 chunk 为 BOS0 + 511 个实际采样 token，T=1、top_p=1、top_k=0、EOS 不停止、无 padding、无质量过滤。模型权重 FP32，CUDA BF16 autocast。1B 的 batch 固定 256；2.8B 先用独立 smoke seed909 做一个 batch128、128 chunks 的完整长度显存测试，peak allocated 不超过 72GiB 才用同一 batch128 正式生成；失败则停止并报告，不静默改 batch 或采样。

两模型均使用已审计的 `artifacts/data_extended/c4_candidate.pt` 作为 C4 候选。CLI 在加载大模型前比较新模型与 C4 tokenizer 的完整 backend JSON（含算法及词表 ID）和 special token 配置，必须完全一致。每 seed 提取 frozen teacher NLL/feature，使用现有 random、dedup_random、五分位 NLL proportional 和 cluster 方法各选 196 chunks；C4 random 同样为 196 chunks。每池 1,000,027 prediction tokens，每银行 100,156；random 对应 B3/B4 共用，C4 对应 B1/B2 共用。

独立输出为 `artifacts/extended/<model>/{generated,banks}/`、`configs/extended/<model>/generation/`、`results/extended_<model>_generation_summary.json`。2.8B 显存 smoke 与正式池分开保存并标记。生成、联合 NLL/features 提取、选择与 clustering 成本、随机种子、重复率、tokenizer 核对、哈希和显存按现有模块记录。所有三 formal seeds 完成后统一审计并通知 root，期间只报告阻塞。
