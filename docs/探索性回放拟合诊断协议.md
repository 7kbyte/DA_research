# 探索性回放拟合诊断协议

本补充由主validation已经观察到的CE/KL差异触发，名称固定为 **post-validation exploratory replay-fit diagnostic**。准备阶段不读真实模型test或行为分数、不运行GPU，独立于primary推断与选参；状态及机器可读协议见 `artifacts/replay_fit_diagnostic_v1/{protocol,manifest}.json`。后续执行须由root另行审预算并冻结scorer/execution SHA。

对严格主B3/B4、b=.05、seed11/22/33，保留共同generated_random库的原196块顺序；从同seed完整1957块pool中严格删除这196个原始selection indices，按原pool索引升序得到1761块complement。每块512token、511个预测位置，因此bank为100,156预测token，complement为899,871，两者合计1,000,027预测token。保留原doc_ids、token位型及原始metadata的SHA引用；检查index唯一、disjoint及完整cover，并拒绝跨分区exact token副本。此处doc_id对应生成chunk，不能把这些块包装为独立自然文档样本。

每seed准备同一initial权重的基线，以及B3/B4各final和best，共3个initial+12个adapted模型案例、每案例评估bank和complement。固定10M target/500K replay的final为主要诊断端点。best由原target validation选择，只作独立次要分层，必须保留真实曝光，不能与final合并或当成等预算。initial权重虽相同，三个seed的库/补集身份不同；只能按base SHA/revision、准确有序tensor SHA、scorer和execution policy共同缓存。同seed的initial结果可供B3/B4和final/best复用，不能复用另一seed或其他corpus的聚合基线。

定义每个分区的变化为ΔNLL=NLL_adapted−NLL_initial；主诊断为

`gap_NLL = ΔNLL_complement − ΔNLL_bank`。

正值表示相对initial，bank的拟合改善大于complement（或退化更小），不等同于证明有害遗忘。主同seed对比是 `gap_B3 − gap_B4`，逐seed完整列出并报告三seed均值、样本SD（ddof=1）与n。另分别给出bank/complement的forward KL(initial teacher || adapted)及相同形式的initial扣除gap，不把数值计算的initial KL强行设为0。评估按预测token加权，保留逐chunk身份，基线与adapted执行策略完全一致。

complement没有进入该random bank，仍来自同一个冻结教师生成pool；整个pool曾参与统计/选库，因而不是新独立test。bank与complement的分布差别、教师生成噪声以及训练路径都可能影响gap；同seedCE/KL控制有助于解释，但单一gap不能证明全部因果机制。本结果不得用于改库、调参、挑主模型、删official-full题目或升级为预注册主结论。保存全部候选与两个端点，不根据诊断结果选择展示。
