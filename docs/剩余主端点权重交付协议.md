实现为 `scripts/export_remaining_primary_endpoints.py`，复用已验收且未修改的 `replay_study.weight_archive` v1 codec。单worker、2个CPU线程、无GPU。每份唯一权重均 encode→decode→与完整原 checkpoint 的每个 model_state tensor 做 uint8 全字节比较；SHA、源文件 stat 和 base 固定身份同时核查，不作浮点差分或量化。压缩率分母是 FP32 model_state 原始字节，不将省略 optimizer 算作压缩收益。记录独立 encode CPU秒、encode wall秒和完整过程 wall/CPU秒；它们不是 GPU 推理成本。

计时口径：每包的 `encode_process_cpu_seconds` / `encode_wall_seconds_sum` 只汇总该包唯一权重的编码阶段。收据 `wall_seconds` 与 `process_cpu_seconds` 从整批启动时累计，因此 best 收据包含先前预算包处理时间，两份收据的累计时间不能相加。完整批次总成本以最后 passed 状态为准；若需 best 的增量 wall，可减去预算包完成时的累计 wall。组包与SHA校验也计入累计成本，不冒充训练或推理成本。

codec内保留 config/counters/provenance/验证选择等字段；另为全部48个逻辑端点保存 `.source_metadata.pt`，包含原 checkpoint 除 model_state 与 optimizer_state 外的**全部**字段，含已有 RNG/stream 状态和未知元数据。保存后重新加载，递归核对 tensor/NumPy位型及其余值。D别名仍有自身来源 SHA、配置、selection 和实际曝光；canonical B4 权重的恢复元数据不冒充D逻辑元数据。这是 model-only 交付，不是完整 optimizer 恢复包。

best 的 checkpoint step/target/replay 与完整训练10M曝光分列，按既有验证选择记录和轨迹核对。D-best 只在已有完整 model-state fingerprint 证据、两侧原 checkpoint SHA 和同seed端点一致时 alias；全部原始源文件仍分别核验。TAR 在 fsync 后逐成员重新哈希，并核完整 TAR SHA，通过后才以无覆盖方式提交最终名称。
