# 主行为分析：静态调用链与首次读取门禁

本次只审阅源码和冻结 manifest，没有运行 check、collect、analyze、verify_outputs，也没有打开任何行为结果、预测或 checkpoint。机器证据为 `results/primary_behavior_analysis_static_review_v1/receipt.json`，包含精确源码 SHA、副本和函数行号。

主 behavior manifest SHA 为 `312d8e150030d489593e7e705699ec1da5f7d505e349ecd15a978eca2c2f7934`，有 67 个推理 job、72 个逻辑端点，其中 6 个为逻辑 alias。其 `common_input_sha256` 只有 8 个小源码/spec 文件，没有 checkpoint。

真实调用路径如下：

1. `guarded_behavior_analysis.check` 核 manifest 和上述小源码 SHA，调用 `inventory_evaluations` 验 attestation 及结果/预测字节 SHA，再核 baseline 的 `verify_outputs`。它不调用 `verified_job`，不传 `scheduler_state`。
2. `guarded_behavior_analysis.analyze` 先检查 ROOT authority，再重复 check，然后调用 `analyze_behavioral_plan.collect` 和 `write_bundle`。
3. collect 使用 `verify_outputs`、`validate_result`，随后读取分数和逐题预测，运行原有统计。`validate_result` 比较结果元数据中的 checkpoint 路径字符串，不打开 checkpoint。
4. `verified_job` 属于实际 GPU dispatcher 的另一条路径：合并 common 和每 job 的 input SHA 并 fresh 全读输入，包含 checkpoint。这条 worker 校验保持原样。

因此，按当前冻结 manifest 和源码路径，guard/check/collect 不包含 checkpoint payload 读取调用。**主行为分析尚未真实运行；这不是一次实测“0-byte 分析”或 0 秒成本。** 先前会话摘要的“分析 fresh 读 233GB CP”不是实际测量记录，不应添加、撤销或改写既有实际成本。未来分析 wall/CPU 仍需计时；结果/预测文件的 SHA 读取也仍有真实成本。

当前 guard 不独立检查完整 scheduler 成功状态，也不写首次语义读取 journal。ROOT 后续必须补做运营门禁，保持原 helper 和统计语义：

1. 在任何分数语义读取前，独立核完整 67 项的冻结定义及实际 state 来源，全部 completed、rc0、无 stop_requested、无 missing_outputs；包括继承的 initial。核初始完整任务集合与 72 个逻辑端点/6 个 alias 的输出凭证、checkpoint 与 model-state 身份。
2. 绑定本次审阅的 guard、collector、analysis 与 manifest/source SHA。独立状态证明通过后，ROOT 才签 `allow_score_analysis=true` 且匹配 manifest、67/72 数量及证明 SHA 的 authority。
3. 经后续明确授权运行原 check；只有 ready 且完整性通过，才独占创建新的 `semantic_access_enabled` journal，绑定 manifest、queue、state proof、authority、源码及 check 收据 SHA。已有 journal 必须拒绝覆盖；失败尝试应保留。该状态表示已允许/准备首次语义读取，不等于解析成功。
4. 再调用原 analyze 到新 output；它仍会复检，然后按原 collect、bootstrap、统计与出图执行。不得改统计或用缺失输出绕门禁。
5. 用 **Bash 内置 time** 包住完整自动化 compound command，即“check 成功 → 独占 journal → 原 analyze”，保存 real/user/sys 与退出码。guard、bootstrap、出图属于同一父项，不能再与父计时相加；此前人工准备、签字和未计时写作仍 unknown。

本审阅未创建 true authority、first-read journal 或分析目录，未修改原 helper、任何科学数值、成本账本或 GPU 队列。
