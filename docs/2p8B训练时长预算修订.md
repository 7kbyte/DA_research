# 2.8B补充实验时长修订（纯计算预算）

在任何2.8B正式训练开始前、行为与test分数仍封存时，root授权按完整矩阵的计时预算一次性选择50M、25M或不启动。组别始终是B0/B1/B2/B4/M×seed11/22/33，共15项，不允许仅跑部分对照或事后截断。原50M方案及其候选配置不覆盖。机器规则见extended_2p8b_horizon_amendment.json；冻结选择见extended_2p8b_horizon_selection.json。

这次选择25M目标预测token。完整优先任务A108、B60、410M/1B各24×100M、全部独立LR/λ pilot与2.8B完整15项一起估算：50M方案加10%周转需18.805小时，剩余17.625小时，不满足；25M方案需16.429小时，满足。两份独立、带SHA的预算记录位于results/supplemental_compute_budget_{50m,25m}_at_horizon_decision.json，旧修订前50M预算另保存在results/supplemental_compute_budget_before_horizon_amendment_50m.json。选择只使用实际计时、完成数量与源SHA；不使用test或行为分数。

25M使用独立命名空间extended_v2_pythia_2p8b_m8_h25m_formal。全部15项从同一预训练checkpoint重新开始，共享25M完整目标暴露LR计划及相同warmup比例。不会在50M计划上训练一半后停止，也不会从已有pilot续训。银行、数据、b=.05、K=100156、micro8×acc8和每153steps验证规则不变。25M为765个optimizer steps、5个验证点，最终回放为1,250,000有效预测token。

每模型仍沿用预先规定的seed101、2M目标暴露、三点LR和四组×四λ的独立短pilot选择，不因时长修订重新调参。该规则能控制方法间选参，不保证25M或50M训练的全局最优。各组同预算、同训练流与LR日程保持可比；2.8B与410M/1B同时存在模型大小、目标暴露、目标重复次数及累计回放暴露的差异，不能解释为纯模型规模因果效应。

只修改辅助配置生成器支持显式完整horizon，冻结train/objectives/evaluate/execution等科学核心未改。27项辅助CPU测试通过，其中新测试验证50M与25M命名空间互不覆盖、15项完整、从初始权重开始且LR日程确实改变；pilot horizon不可被该override修改。后续执行仍须先审计完整19项校准并生成独立input snapshot。
